# 🎤 発音クリッカー

**放置するより、発音するほうが速い。** ── 英単語の発音練習 × 放置系クリッカーゲーム

英単語をマイクに向かって発音し、音声認識が正しさを判定。正解すると資金がもらえ、資金で「単語帳 → オンライン英会話 → 英会話教室 → 海外留学 → …」と学習環境を育てていきます。最後にどこへたどり着くかは、遊んでのお楽しみです。

制作の動機は、日本の中高生の英語学習における「スピーキング量の不足」の解消です。話す練習だけは相手や環境が必要で、家庭学習から抜け落ちがちです。本アプリは「一人で・何度でも・機械が判定してくれる」発音練習の場を、ゲームの成長要素と直結させます。

## 動作方法

**最も簡単な方法: ブラウザで以下を開くだけで動作します（インストール不要）**

> https://stahmite.github.io/hatsuon-clicker/
>
> 進行済み状態: [中盤から](https://stahmite.github.io/hatsuon-clicker/?demo=mid) / [終盤直前から](https://stahmite.github.io/hatsuon-clicker/?demo=end)

Google Chrome を推奨します（Web Speech APIのため）。マイクの使用を許可してください。

**スマートフォンにも対応しています。** スマホのブラウザ（Android版Chrome推奨）で同じURLを開くだけで、モバイル最適化されたレイアウトで動作します。

ローカルで実行する場合は以下の手順です。ビルド・インストールは不要です（静的なHTML/CSS/JavaScriptのみ）。

1. このリポジトリをダウンロード（Code → Download ZIP）して展開
2. フォルダ内でローカルサーバーを起動してください（音声認識はfile://では動かず、localhostまたはhttpsが必要です）
   - 例: `npx serve . -p 3000`（Node.js） / `python -m http.server 3000`（Python）
3. **Google Chrome** で `http://localhost:3000` を開く（Web Speech APIを使うため Chrome または Edge を推奨）
4. マイクの使用を許可し、表示された英単語を発音してください

マイクが使えない環境では、単語表示の下のキーボード入力欄からも判定を試せます。

### 進行済みデータでの確認（デモモード）

ゲームが進んだ状態を確認したい場合は、URLにパラメータを付けてアクセスしてください。

| URL | 状態 |
|---|---|
| `http://localhost:3000/?demo=mid` | 中盤（施設6種・図鑑150語・実績一部解除） |
| `http://localhost:3000/?demo=end` | 終盤直前（施設11種・図鑑480語・最終施設がすぐ購入できる残高）。ここで最終施設を購入すると、クリア演出（経済ゴール達成）を確認できます |

※デモデータは既存のセーブを上書きします。最初からやり直す場合は 設定(⚙️) → データリセット を押してください。

## 主な機能

- **発音判定**: Web Speech APIの認識結果と正解単語を文字単位でアライメント（レーベンシュタイン法）し、一致率を算出。発音精度を%表示し、発音記号上のずれた箇所を色分け表示
- **経済設計**: 施設による毎秒の自動収入がどれだけ育っても、発音1回の報酬（自動生産3秒分ボーナス込み）が常に上回る比例設計。コンボ（最大+50%）・図鑑ボーナス・発声トレーニングの伸びはすべて発音側のみに乗るため、放置ではなく発音がクリアへの最短ルートになる
- **学習サポート**: 惜しい発音への努力賞 / 判定難易度3段階（救済判定） / スキップした単語の自動再出題 / 単語図鑑（5語ごとに全収入アップ） / ブックマーク / お手本のTTS再生（低速再生対応）
- **収録語彙**: 513語（中学〜高校・資格試験レベルの4段階）
- **その他**: PC・スマートフォン両対応（レスポンシブUI） / 実績システム / ダークモード / キーボードショートカット（Space:マイク・L:お手本・S:スキップ） / スクリーンリーダー向けaria-live対応

## 設計のこだわり

- **買い物も単語ドリル**: 施設購入の確定ワードは、初回はその施設名、2回目以降は「まだ覚えていない単語」から優先出題。正解すると図鑑にも登録されるため、買い物のたびに語彙が1つ増えます
- **意味は「後出し」**: 日本語訳は正解・スキップ後にのみ表示。「思い出してから答え合わせ」の順序で、発音練習が同時に語彙の想起練習になります
- **スキップは罰ではなく学習イベント**: 減点なしで、その場で意味とお手本音声を提示し、ブックマーク導線を出します。スキップした単語は図鑑に「仮登録」として残り、図鑑から発音練習に合格すると本登録に昇格——集めたい気持ちがそのまま復習動機になります
- **詰まりを検知する適応型判定**: Normal難易度でも同じ単語で3回つまずくと判定が自動で緩み、惜しい発音を拾って前に進めます
- **音声まわりの排他制御**: お手本再生中はマイクを自動停止し終了後に復帰（アプリが自分の合成音声を「発音」と誤認識しない）。正解演出中は判定をロックし二重判定を防止
- **誤り箇所ハイライトの安全弁**: 認識結果とのアライメントで得た文字単位の誤り位置を発音記号列へ写像して色分け。誤りが大きすぎる場合は部分表示をやめて全体強調に切り替え、不正確なフィードバックを出しません
- **データも手作り**: 513語すべてに発音記号・品詞・和訳を整備。難しい単語ほど報酬が高いレベル連動設計で、「難語への挑戦」が最も稼げる行動になっています
- **細部の堅牢性**: 効果音は音源ファイルなしのWeb Audioリアルタイム合成／タブを裏に回しても放置収入は実経過時間で計算され失われない／セーブデータは項目単位で検証する後方互換ロード／通貨表示はK〜Dc（10^33）の11段階対応
